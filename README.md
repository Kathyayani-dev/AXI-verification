# AXI-verification
The AXI Verification Project is about building a reusable test environment for the AMBA AXI protocol, usually AXI4 or AXI4‑Lite. The AXI protocol is commonly used for fast on‑chip communication, inside system‑on‑chip devices. The goal of the AXI Verification Project is to make the AXI testing setup easy to reuse in projects.
